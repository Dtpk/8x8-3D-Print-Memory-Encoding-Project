So the .bas file is to be ran on DOS systems using qbasic. I am currently using qbasic 4.5.
The .py can be laucnhed in python under Windows or Linux and doesn't need any requirements.

Update single write generator build in openscad is up you can either use online versions of openscad or a local instants to run the openscad code give it a few words tell it if you want a notch or keychain hole set the size ect then print and you got yourself a coaster/keychain with data you only see when it got a light behind it. Please test the bits first in the preview before printing there is little error protection. 

Keychain size is 32mm by 32mm 0.4mm height printed with no infill but might be better with it I have not tried yet.

I am also testing with no infill and 2 layer top and bottom total thickness is 8 layers in the slicer.

The airsoft re-writable version will be up next you will need to punch the back single layer out this is for easy printing on 3D printers since it wont force the printer to draw 64 holes.
